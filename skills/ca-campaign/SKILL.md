# Campaign: make it so

**Purpose:** Steady improvement, little human effort.

## Steps
1. Read `CHARTER.md` and `docs/daneel/STATE.md`.
2. New? Run the stages in order. Resuming? Check drift first.
3. Apply proportion throughout.
4. Queue gates, never interrupt; stop at shipshape or budget.

## Routes
- `ca-campaign-survey/SKILL.md`: map it.
- `ca-campaign-align/SKILL.md`: best practice.
- `ca-campaign-proportion/SKILL.md`: cut excess.
- `ca-campaign-plan/SKILL.md`: plan, timeframe.
- `ca-campaign-execute/SKILL.md`: deliver.
- `ca-campaign-guardrails/SKILL.md`: rules for all agents.
- `ca-campaign-drift/SKILL.md`: check others' changes.
- `ca-campaign-report/SKILL.md`: report.
