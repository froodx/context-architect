# Plan

**Purpose:** A doable plan, approvable in five minutes.

## Steps
1. Score candidates by value, risk and effort; apply proportion.
2. Draw a cut line; list what is deliberately not being done.
3. Milestones of one to five sessions, each turning scorecard lines green, about a quarter strategic.
4. Size each ticket to one fresh context window.
5. Timeframe: sessions per milestone, plus human review time, with a range.
6. Write ADRs only for the few decisions that need them.
7. Name the gates the person must approve.

## Output
`docs/daneel/PLAN.md` and a one-paragraph summary for the person.
