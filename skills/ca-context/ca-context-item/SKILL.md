# Context item

**Purpose:** Every item says what it is, where it came from and whether to trust it.

## Steps
1. Kind: instruction, knowledge, state, capability or example.
2. Add facets: who, what, when, where, why, which, how.
3. Add lifespan, sensitivity, readable by and writable by.
4. Scale fields to stakes: a perishable note needs what, when and who; a costly decision needs all.
5. Kinds carry obligations: instructions need authority; knowledge needs a source and date.
6. Separate fact from interpretation.

## Output
A record in `../../context-architect/references/context-item.yaml` form. Example: `../../context-architect/references/worked-example.md`.
