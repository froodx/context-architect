# Steer

**Purpose:** Direct work so tactical speed adds up to strategic value.

## Cycle
Align, Specify, Decompose, Implement, Verify, Reflect. Scale it to risk: a rename skips to Implement; payments get every step.

## Routes
- `ca-steer-spec/SKILL.md`: write the specification.
- `ca-steer-decompose/SKILL.md`: split into tickets.
- `ca-steer-roadmap/SKILL.md`: set long-range direction.
- `ca-steer-rollout/SKILL.md`: change live systems safely.
- `ca-steer-ratchet/SKILL.md`: turn lessons into checks.

## Elsewhere
Align uses `../ca-orient/SKILL.md`. Implement uses `../ca-swarm/SKILL.md`. Verify uses `../ca-review/SKILL.md`.

## Output
Specs, tickets, roadmaps and ratchets.
