# Swarms

**Purpose:** Use many agents only where it pays, and keep them safe.

## Principle
In a swarm, the ontology and the boundaries do the orchestrating.

## Routes
- `ca-swarm-topology/SKILL.md`: choose a shape, or none.
- `ca-swarm-contract/SKILL.md`: brief each worker.
- `ca-swarm-blackboard/SKILL.md`: share state with provenance.
- `ca-swarm-boundaries/SKILL.md`: isolate and limit workers.
- `ca-swarm-loops/SKILL.md`: brake self-running loops.

## Output
A topology, contracts and boundaries that a human can read in minutes.
